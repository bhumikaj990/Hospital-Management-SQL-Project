# Hospital Management & Patient Analysis | SQL Project

# About the Project
This project focuses on analyzing hospital patient and appointment data using MySQL.
The project helps explore patient demographics, doctor performance,
appointment status, and department-wise revenue using SQL queries.

# Project Dataset

* 30 Patients
* 10 Doctors
* 50 Appointments

# Tools & Technologies

* MySQL
* SQL
# Key Analysis

* Appointment Status Analysis
* Doctor Performance Analysis
* Department-wise Revenue
* Monthly Revenue Analysis
* Repeat Patient Identification

# SQL Concepts Used

SELECT | WHERE | GROUP BY | HAVING | JOINs | Subqueries | Aggregate Functions | Window Functions


Improved SQL querying, data analysis, and reporting skills by working with relational hospital data.
This project uses sample data for learning and portfolio purposes.
